# Security Policy

## Supported Versions

Only the latest release on the `main` branch receives active security updates and vulnerability patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this pharmacy and medical store management application seriously. If you discover a security vulnerability, please report it responsibly:

1. **Do not create a public GitHub issue** for undisclosed security vulnerabilities.
2. Please submit a private advisory through GitHub's Security Advisories tab:  
   `https://github.com/jagmohan-kurmi/medical-store/security/advisories/new`
3. Alternatively, contact the maintainer directly at `7509879289.jp@gmail.com` with the subject `[SECURITY VULNERABILITY] Medical Store Management`.

Please include:
- A description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or proof-of-concept code.
- Affected URL endpoints, parameters, or configurations.

### Response Commitment

- Acknowledgement of receipt within 48 hours.
- Assessment of validity and severity within 5 business days.
- Patch development and coordination of public disclosure after fix verification.
